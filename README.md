# 🚀 Trinova Digital — Landing Page & CMS Platform

Platform Landing Page modern, super-cepat, dan interaktif yang dibangun menggunakan ekosistem PHP/Laravel untuk membantu brand e-commerce/UMKM naik kelas.

## 🛠️ Tech Stack
*   **Framework**: Laravel 12
*   **Frontend**: Livewire 3 + Alpine.js
*   **CSS Framework**: Tailwind CSS v4
*   **Build Tool**: Vite

---

## 💻 Cara Menjalankan Dev Server

Buka terminal di folder project, pastikan server database (MySQL/Laragon/XAMPP) sudah menyala, lalu jalankan:

```bash
# Jalankan server lokal Laravel dan compiler HMR secara bersamaan menggunakan bat file helper
run_dev.bat
```

Atau jalankan secara manual di dua terminal terpisah:

**Terminal 1 (Laravel)**:
```bash
php artisan serve
```

**Terminal 2 (Vite)**:
```bash
npm run dev
```
