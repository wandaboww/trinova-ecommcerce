# DATABASE.md

# Trinova Landing Page & Digital Growth Platform

# Database Philosophy

Database dirancang dengan prinsip:

- Normalize First
- Soft Delete bila diperlukan
- UUID Ready
- SEO Friendly
- Scalable
- Audit Friendly

Semua tabel wajib memiliki:

```sql
id
created_at
updated_at
```

Untuk tabel penting gunakan:

```sql
deleted_at
```

# AI Query Rules

AI wajib memahami relasi sebelum membuat query.

Gunakan Eloquent Relationship.

Prioritaskan:

- eager loading (`with()`)
- pagination
- scopes
- repository

Hindari:

- N+1 Query
- Query di Blade
- Raw SQL tanpa alasan yang jelas
- Query berulang pada Controller

# Future Expansion

Struktur database disiapkan agar mudah dikembangkan untuk fitur berikut:

- CRM sederhana
- Pipeline penjualan
- Reminder follow-up
- Kalender meeting
- Proposal digital
- Invoice
- Payment tracking
- Client portal
- Maintenance subscription
- AI Chat Assistant
- Email marketing
- WhatsApp automation
- Knowledge base

Seluruh tabel baru harus tetap mengikuti prinsip pemisahan tanggung jawab, mendukung skalabilitas, dan tidak mengubah struktur tabel lama tanpa kebutuhan yang jelas.
