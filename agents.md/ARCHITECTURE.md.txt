# ARCHITECTURE.md

# Trinova Landing Page & Digital Growth Platform

# Architecture Principle

Project menggunakan arsitektur yang bersih (Clean Architecture) dengan pendekatan:

```
Controller
    ↓
Form Request
    ↓
Service
    ↓
Repository
    ↓
Model
    ↓
Database
```

Controller tidak boleh berisi business logic.

Business logic harus berada di dalam Service.

Repository bertanggung jawab terhadap query database.

Model hanya merepresentasikan data.

Blade hanya bertugas menampilkan data.

# Layer Responsibility

## Controller

Lokasi

```
app/Http/Controllers
```

Tugas:

- menerima request
- memanggil Service
- mengembalikan View atau Response

Tidak boleh:

- query database
- business logic
- validasi manual

---

## Form Request

Lokasi

```
app/Http/Requests
```

Tugas:

- validasi input
- authorization

Semua validasi wajib menggunakan Form Request.

---

## Service

Lokasi

```
app/Services
```

Service adalah pusat business logic.

Semua proses seperti:

- membuat data
- update
- delete
- generate slug
- upload file
- sinkronisasi data
- SEO
- workflow

ditulis di sini.

Controller hanya memanggil Service.

---

## Repository

Lokasi

```
app/Repositories
```

Semua query database ditempatkan di sini.

Contoh:

```
ArticleRepository

ProgramRepository

LeadRepository

PortfolioRepository
```

Repository bertanggung jawab:

- find
- paginate
- filter
- search
- create
- update
- delete

---

## Model

Lokasi

```
app/Models
```

Model hanya berisi:

- relationship
- casts
- accessor
- mutator
- scope sederhana

Business logic tidak boleh ditaruh di Model.

---

## Blade

Lokasi

```
resources/views
```

Blade hanya bertugas:

- looping
- if sederhana
- menampilkan data

Blade tidak boleh:

- query database
- business logic
- perhitungan kompleks

# AI Coding Rules

AI harus selalu menentukan layer yang tepat sebelum menulis kode.

| Kebutuhan | Lokasi |
|-----------|--------|
| Validasi Form | Form Request |
| Business Logic | Service |
| Query Database | Repository |
| Relationship | Model |
| Routing | routes/web.php |
| Tampilan | Blade |
| Middleware | Middleware |
| Authorization | Policy |
| Helper Function | Helpers |
| Enum | Enums |
| DTO | DTO |

# Project Goal

Project ini bukan sekadar website company profile.

Project ini adalah **Marketing Engine** yang memiliki satu tujuan utama:

Mengubah traffic menjadi lead.

Mengubah lead menjadi project.

Mengubah project menjadi repeat client.

Seluruh pengembangan fitur, desain UI, struktur halaman, maupun implementasi kode harus selalu mendukung tujuan tersebut.

Jika suatu fitur tidak memberikan dampak terhadap conversion, trust, user experience, SEO, atau efisiensi operasional, maka fitur tersebut harus dievaluasi kembali sebelum diimplementasikan.
