# Core Philosophy

Project ini bukan website company profile.

Project ini adalah **Marketing Engine**.

Setiap module harus memiliki tujuan yang jelas dalam sales funnel.

```
Traffic

↓

Attention

↓

Trust

↓

Lead

↓

Meeting

↓

Project

↓

Repeat Client
```

Apabila sebuah module tidak mendukung salah satu tahapan di atas, maka module tersebut perlu dievaluasi kembali.

# Golden Rules

Setiap module wajib menjawab minimal satu pertanyaan berikut:

- Apakah module ini menarik perhatian pengunjung?
- Apakah module ini membangun kepercayaan?
- Apakah module ini mengedukasi calon klien?
- Apakah module ini meningkatkan konversi?
- Apakah module ini membantu SEO?
- Apakah module ini mempermudah proses penjualan?
- Apakah module ini meningkatkan peluang repeat order?

Jika jawabannya **tidak**, maka module tersebut bukan prioritas untuk dikembangkan.
